# AI Start

Мой первый проеект в области искусственного интеллекта 

## Что здесь есть 

- `main.py` - первый кодб проверка рабочего окружния. 
- `chat.py` - чат-бот для терминала с сохронением истории диалога.
- `bot.py` - Telegram-bot с искусственным интллектом.

## Что умеет Telegram-бот

- Отвечает на сообщния в Telegram через модель openia/gpt-oss-120b`
(Groq API).
- Помнить контекст диалога для каждого пользователья.
- Ключи хранятся в `.env`, не попадают в Git.

## Стек

- Python 3.14
- aiogram (Telegram)
- Groq API (LLM)
- python-dotenv

## Как запустить 

1. Клонировать репозиторий.
2. Создать вртуальное окружение: `python -m venv .venv`
3. Активировать: `.venv\Scripts\activate` (Windows)
4. Установить  зависимости: `pip install aiogram groq python-dotenv`
